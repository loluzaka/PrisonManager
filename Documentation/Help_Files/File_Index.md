# Legacy Oracle File Index - one help file per original project file

These beginner guides explain the historical Oracle SQL/scripts listed below. Their Oracle run order is not the active PostgreSQL deployment process; use `postgres/install.sql` and the PowerShell scripts in `scripts/` for the current project.

Every original SQL/script project file has its own beginner-friendly help file with ten sections: overview, dependencies, keyword explanation, tables and columns, walkthrough, a real execution example, data flow, common errors, viva questions and practical commands. The web UI is documented in `README.md` and `Documentation/Cloud_Setup.md`.

Project-wide documents: [README](../../README.md) · [Architecture](../Architecture.md) · [ER diagram & BCNF](../ER_Diagram.md) · [Data dictionary](../Data_Dictionary.md) · [Testing guide](../Testing_Guide.md) · [Cloud setup](../Cloud_Setup.md) · [Feature traceability](../Feature_Traceability.md)
